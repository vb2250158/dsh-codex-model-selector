# DSH Codex Model Selector

## 0.1.6

- 修复浏览器原生 `fetch` 被当作统计对象方法调用而触发 `Illegal invocation`，恢复实际请求记录参与常用模型排名。

## 0.1.5

- 模型入口先展示最近 30 天常用的最多 6 个模型，每项显示目录中的模型名称和提供商；完整目录与搜索收进“更多模型”，重定向规则编辑器共用此下拉。
- 排名合并用量插件记录的实际助手请求次数与此选择器成功切换模型的次数，次数相同时最近使用优先。提供商和模型 ID 共同作为身份，隐藏或已不可用的目录项不占常用名额。没有记录时保留“更多模型”入口。
- 请求记录读取已安装用量插件的公开 `/usage/api` 接口；成功选择记录从此版本开始保存在当前浏览器，规则草稿、失败选择和推理档位调整不计数。用量接口不可用时提示并使用已有记录，完整目录仍可操作。客户端更新后刷新页面生效。

## 0.1.4

- 中间模型入口悬停时显示贴合文字区域的圆角底色，按下时加深；键盘聚焦显示底色和轮廓。输入框模型按钮悬停也有背景变化，颜色跟随当前主题。

## 0.1.3

- 向模型列表设置提供 `settings.model-redirect.picker` 槽位，与输入框共用 `ModelSelect` 搜索下拉。规则编辑只回传草稿，不切换当前会话；Escape 关闭搜索列表。

- 输入框按钮显示“模型名称 · 提供商”，名称、大小写和空格取自模型目录；目录缺失时保留原始 ID。推理等级单独显示。

独立的模型选择器样式插件。紧凑卡片包含模型入口、推理等级分档滑条及默认等级重置；模型列表支持按提供方或模型的名称和 ID 本地搜索，模型和等级数据仍来自官方 `modelDirectories` 服务。选择经原有接口保存，不另建配置数据源。

安装：`dsh plugin --profile web add github:vb2250158/dsh-codex-model-selector#<commit>`，重启 DSH 并刷新页面。禁用插件会释放模型槽和样式，恢复官方选择器。无需修改官方源码。

组件基于 DeepSeek 的 MIT 授权 ModelSelect 改写，保留原有失败反馈、加载重试和模型分组。版权见 LICENSE。源码和构建产物均在此插件内维护。

验证：`pnpm test`，`pnpm run build`。

闪电按钮复用已安装订阅插件的 `loadSpeed` / `setSpeed` 注入接口：只有当前模型目录确认支持快速档时才可操作。普通速度控件在本插件启用时被同一槽位的较高优先级空视图替代，避免重复入口；卸载本插件自动恢复。快速模式会使用更多用量。底部按钮同时显示模型名称与推理等级。

配色全部继承 DSH 主题变量；插件只调整布局、尺寸和控件形状，不覆盖主题色。
滑条拖动过程中只预览档位，松手后提交一次。保存导致的临时失焦不会关闭卡片；点击外部或按 Escape 仍可关闭。
快速模式开启时，收起状态的模型按钮在模型名前显示实心闪电；首次加载也会读取已有速度状态。

将 `<commit>` 替换为本仓库完整提交号。插件代码与运行所需产物随 Git 交付；用户设置、凭据和聊天记录不属于本仓库。

卡片中央的强度文字、模型名称与提供商名称共用一个换模型按钮；提供商名称来自当前模型目录，目录缺失时显示提供商 ID，长名称截断后可悬停查看。思考强度由下方滑条和右侧重置按钮调整。

拖动强度滑条时，卡片级别文字实时预览当前档位，松手后保存；取消拖动恢复已保存的级别。
